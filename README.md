# Keyword Checker in Java  

## Description  
This Java program checks whether a given word is a keyword from a predefined list. The program takes user input and compares it with an array of keywords. If the input matches any keyword, it prints a confirmation message; otherwise, it states that the word is not a keyword.  

## Features  
- Accepts a single-word input from the user.  
- Compares the input with a predefined list of keywords.  
- Displays whether the input is a keyword or not.  

## Prerequisites  
- Java Development Kit (JDK) installed  
- A Java IDE or terminal with Java support  

## Usage  
1. Compile the program using:  
   ```sh
   javac Main.java
   ```  
2. Run the program:  
   ```sh
   java Main
   ```  
3. Enter a word when prompted.  
4. The program will check if the word is a keyword and display the result.  

## Example Output  
```
Input: if  
Output: if is a keyword  

Input: hello  
Output: is not a keyword  
```

## Keywords List  
The program checks against the following keywords:  
`case, continue, break, defer, default, if, else, for, func, goto, map, struct, type, return, range, var`
